# CodiAI

Локальный AI-ассистент для Windows, версия 0.8.7. Интерфейс чата, память, поиск, голосовой ввод, помощник на экране и работа с проектами.

**Основа ответов — готовые модели Qwen через Ollama.** CodiAI — приложение и инструменты вокруг модели, а не нейросеть, обученная с нуля. Изучение сайтов сохраняет материалы в базе знаний и не меняет веса модели.

## Установка

1. Распакуйте проект в отдельную папку, например `D:\Projects\CodiAI`.
2. Установите Python 3.12+ с Tcl/Tk и Python Launcher с https://www.python.org/downloads/windows/ и Ollama с https://ollama.com/ . Нужен Edge или Chrome; встроенный браузер использует WebView2.
3. В PowerShell из папки проекта выполните `powershell -ExecutionPolicy Bypass -File .\Setup-CodiAI.ps1`. Скрипт создаёт локальную среду и устанавливает Python-зависимости. Интернет требуется для загрузки зависимостей.
4. Для запуска Ollama с параметрами CodiAI предварительно завершите уже работающий Ollama через его значок в трее. Запустите `Start-CodiAI.cmd`.
5. В разделе «Модели» скачайте выбранную модель. Для качества можно выбрать Initial 0.2 — `qwen3:4b-instruct`. Начальная модель — `qwen3:1.7b`. Для поиска по смыслу нужна `embeddinggemma`, для анализа картинок — vision-модель, предлагаемая приложением.

Модели, память, профили браузера и остальные рабочие данные не включены в репозиторий. Новая установка начинает с пустой памятью. Локальный движок запускается на CPU; скорость зависит от компьютера. Если Ollama уже работает отдельно, приложение использует его текущую конфигурацию.

Голосовой ввод дополнительно требует русскую модель Vosk `vosk-model-small-ru-0.22`: скачайте её с https://alphacephei.com/vosk/models и распакуйте в `runtime/speech/vosk-model-small-ru-0.22`.

## Возможности и ограничения

- Чат, режимы программиста, учителя, ролевого общения, поиска, Code With Codi и «3D и персонажи».
- Работа с файлами в подключённой папке: предложения правок, запись с проверкой и резервными копиями. Доступные тесты и сборка требуют соответствующих инструментов проекта.
- Память, изучение публичных сайтов и YouTube, продолжение и удаление тем, перенос памяти файлом. YouTube разбирается по доступным субтитрам; кадры и звук не анализируются. Каналы обрабатываются порциями.
- SVG, OBJ/MTL, glTF JSON и Python-скрипты Blender. Blender и растровый генератор не входят в поставку; качество рисунка или модели не гарантируется.
- Помощник может выполнять поддержанные команды файлов и запуска программ, анализировать снимки экрана. Экспериментальное управление играми не гарантирует прохождение.
- Собственные справочные материалы можно добавлять в «Знания». Личная библиотека из рабочей установки не включена в архив.

## Конфиденциальность

Для локального чата API-ключ не нужен. Запросы к модели отправляются в локальный Ollama. Поиск и изучение сайтов обращаются в интернет; встроенный браузер обращается к открываемым сайтам. Чаты, память, вложения, настройки, резервные копии и браузерные профили сохраняются в `data/` и не должны публиковаться.

Сервер предназначен для личного использования на localhost. Не выставляйте порт 8765 в публичную сеть. Помощник меняет файлы и запускает программы с правами пользователя: выбирайте рабочую папку осознанно.

## Проверка

```powershell
.\runtime\python\python.exe -m unittest discover -s tests
```

## Публикация на GitHub

Загружайте содержимое этой чистой папки. Не копируйте сюда `data/`, `runtime/`, свои настройки, журналы, экспорты памяти и `.env`. `.gitignore` защищает от случайного добавления распространённых файлов, но не заменяет проверку перед публикацией. Архив и локальный отчёт проверки загружать в репозиторий не требуется.

## Сторонние компоненты

Python-зависимости перечислены в `requirements.txt` и распространяются на условиях их авторов. Ollama, Qwen, модели Vosk и другие веса загружаются отдельно; соблюдайте их лицензии. Этот архив не включает веса, установщики и чужие справочные материалы. Отдельная лицензия исходников CodiAI пока не выбрана.
